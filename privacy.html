개인정보처리방침

시행일 2026년 9월 30일

1. YouTube API 서비스 사용

CC Shorts Uploader(이하 “이 도구”)는 YouTube API 서비스를 사용합니다. 이 도구를 사용하면 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

2. 사용 대상

이 도구는 운영자 한 사람이 자신의 YouTube 채널에 영상을 올리는 데에만 씁니다. 다른 사람의 계정이나 채널에는 접근하지 않습니다.

3. 접근·수집·저장하는 정보

  • 요청 권한: https://www.googleapis.com/auth/youtube.upload 하나만 요청합니다. 영상을 올리는 권한이며, 채널의 다른 정보를 읽는 데 쓰지 않습니다.
  • 인증 토큰: Google 로그인 후 받은 OAuth 토큰은 운영자 컴퓨터의 로컬 파일에만 저장하며, 운영자만 읽을 수 있게 권한을 제한합니다. 서버나 제3자에게 보내지 않습니다.
  • 업로드 기록: 올린 영상의 ID·주소·올린 시각을 운영자 컴퓨터에 기록해 같은 영상을 두 번 올리지 않게 합니다.
  • 이름, 연락처, 시청 기록, 구독자 정보 등 그 밖의 개인정보는 수집하지 않습니다. 쿠키나 분석 도구를 쓰지 않습니다.

4. 이용 목적

위 정보는 운영자가 만든 영상을 운영자 채널에 올리는 목적에만 씁니다.

5. 제3자 제공

어떤 정보도 판매하거나 제3자에게 제공하지 않습니다. 영상과 제목·설명은 업로드를 위해 YouTube(Google)로만 전송됩니다.

6. 보관 기간과 삭제

토큰은 권한을 철회하거나 운영자가 파일을 지울 때까지 보관합니다. 권한을 철회하면 토큰은 더 이상 쓸 수 없고, 운영자 컴퓨터의 토큰 파일도 삭제합니다. 삭제를 요청하려면 아래 문의 주소로 연락하세요. 7일 안에 처리합니다.

7. 권한 철회

언제든지 Google 계정의 보안 설정(타사 앱 액세스)에서 이 도구의 권한을 철회할 수 있습니다.

Privacy Policy

Effective September 30, 2026

1. Use of YouTube API Services

CC Shorts Uploader (“the tool”) uses YouTube API Services. By using the tool you are also subject to the YouTube Terms of Service and the Google Privacy Policy.

2. Who uses it

The tool is used only by its single operator to upload videos to the operator's own YouTube channel. It does not access any other account or channel.

3. Information accessed, collected and stored

  • Scope: only https://www.googleapis.com/auth/youtube.upload is requested, used solely to upload videos.
  • Auth token: the OAuth token obtained after Google sign-in is stored only in a local file on the operator's computer, readable only by the operator. It is never sent to any server or third party.
  • Upload log: the ID, URL and time of each uploaded video are recorded locally to avoid duplicate uploads.
  • No other personal data (name, contacts, watch history, subscribers, etc.) is collected. No cookies or analytics are used.

4. Purpose

This information is used only to upload the operator's own videos to the operator's own channel.

5. Sharing

No information is sold or shared with third parties. Videos and their titles and descriptions are sent only to YouTube (Google) for uploading.

6. Retention and deletion

The token is kept until access is revoked or the operator deletes the file. When access is revoked, the local token file is deleted. To request deletion, contact the address below; requests are handled within 7 days.

7. Revoking access

You can revoke the tool's access at any time from the Google security settings page.
